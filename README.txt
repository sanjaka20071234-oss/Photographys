# Pixel Lens Photography Website

## Files
- `index.html` — website structure and content
- `style.css` — responsive design, animations and layout
- `script.js` — mobile navigation, gallery filters/lightbox and WhatsApp booking

## Preview
Open `index.html` in a browser. Internet access is needed for Google Fonts and the externally hosted sample photographs.

## WhatsApp booking
The booking form opens WhatsApp with the customer's details pre-filled for **+94 76 060 9648**. The customer must press Send in WhatsApp. This is a booking request, not an automatic confirmed reservation.

## Before publishing
1. Replace the sample Unsplash photos with the photographer's own portfolio images.
2. Add the official Facebook and Instagram page URLs when available. No unverified social links are included.
3. Confirm the displayed business contact number is correct.
4. Upload all three website files to a web host (for example, GitHub Pages or Netlify).

Sample gallery photographs are illustrative and are not represented as Pixel Lens's own work.
